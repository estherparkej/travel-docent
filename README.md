# 여행 도슨트

미술관 오디오 가이드처럼, 여행지에서 **지금 서 있는 자리**를 GPS로 알아내고
그곳의 이야기를 목소리로 들려주는 웹앱입니다.

> "지금 당신이 서 계신 곳은 경주 불국사 다보탑입니다.
>  대웅전 앞뜰에서 석가탑과 마주 보고 서 있는 탑이지요…"

## 어떻게 동작하나

```
휴대폰 브라우저 ──GPS 좌표──▶ server.py
                                 │
                                 ├─▶ 위키백과 (좌표 → 주변 문화재 + 사실 자료)   [무료·가입 불필요]
                                 │
                                 └─▶ AI (사실 자료 → 도슨트 말투 대본)          [선택]
       ◀──문장이 완성될 때마다 스트리밍──┘
휴대폰이 문장 단위로 소리내어 읽음 (브라우저 내장 음성합성)
```

**사실은 위키백과에서 가져오고, AI는 말투만 입힙니다.** 그래서 연도나 인명을
지어내지 않습니다. AI 키가 없으면 위키백과 원문을 다듬어 그대로 읽어줍니다.

## 바로 실행 (키 없이)

```bash
cd "/Users/eunjungpark/claude/travel-docent 2" && .venv/bin/python server.py
```

이 상태로도 앱 전체가 동작합니다. 말투가 백과사전식일 뿐입니다.

## 도슨트 말투로 바꾸기 (무료, 5분)

1. https://aistudio.google.com/apikey 접속 → 구글 계정으로 로그인
2. **Create API key** 클릭 → 키 복사 (**카드 등록 없음, 무료 한도 안에서 과금 없음**)
3. 아래 명령으로 `.env` 파일을 열고

   ```bash
   open -e "/Users/eunjungpark/claude/travel-docent 2/.env"
   ```

4. `GEMINI_API_KEY=` 뒤에 키를 붙여넣고 `⌘S` 저장

서버는 켜둔 채로 두면 됩니다. 요청마다 `.env`를 다시 읽습니다.
제대로 들어갔는지는 이렇게 확인합니다:

```bash
curl -sk https://localhost:8443/api/health
```

`"provider": "gemini"` 가 나오면 성공입니다.

| provider 값 | 뜻 |
|---|---|
| `wiki` | 키 없음. 위키백과 원문을 읽어줌 |
| `gemini` | Gemini 무료 한도로 도슨트 말투 생성 (`gemini-3.6-flash`) |
| `claude` | 유료 Claude API 사용 (키가 있으면 이쪽이 우선) |

## 휴대폰에서 쓰기

브라우저는 **HTTPS에서만 GPS를 허용**하므로 서버가 자체 서명 인증서로 HTTPS를 씁니다.

1. 휴대폰을 컴퓨터와 **같은 와이파이**에 연결
2. 터미널에 표시된 `https://192.168...:8443` 주소를 휴대폰 브라우저에 입력
3. "안전하지 않은 연결" 경고 → **고급 → 계속 진행** (내 컴퓨터라 안전합니다)
4. 위치 권한 **허용** → **지금 여기 안내 받기**

## 책상에서 시험해보기

`https://localhost:8443` 을 열고 **⚙ 설정 → 장소 직접 입력**에
`경주 불국사` 처럼 적으면 GPS 대신 그 장소로 해설합니다.

## 화면

구조는 음악 플레이어를 따릅니다. **장소 하나가 한 곡**입니다.

```
┌──────────────────────┐
│ 지금 재생 중       ⋮ │
│                      │
│   [ 사진 캐러셀 ]     │  ← 좌우로 스와이프
│                      │
│   ⋯ 이미지가 마스크로  │
│      녹아 사라짐 ⋯    │
│ ▪▫▫▫▫▫▫▫             │  ← 몇 번째 사진인지
│ 불국사                │
│ AI 도슨트 · 다보탑     │
│ ────────────────     │  ← 진행바 (시간은 끌 때만)
│  ⤨  ⏮  (▶)  ⏭  🚶   │
│ 지금 읽는 문장…        │
│  ●    ▬    ◷         │
└──────────────────────┘
```

### 이미지와 UI의 경계

경계선이 생기지 않도록 **색을 맞춰 덮지 않고, 이미지 자체를 마스크로 지웁니다.**
`mask-image` 로 33%부터 75%까지 열두 단계에 걸쳐 감쇠시키면 사진 아래에는
바탕 그라데이션만 남습니다. 맞출 두 번째 색이 없으니 이음매가 생길 수 없습니다.

### 사진 캐러셀

- 그 장소의 사진을 **여러 장** 모아 좌우 스와이프로 넘깁니다 (`scroll-snap`)
- 넘길 때마다 **그 사진에서 뽑은 색으로 화면 전체가 물듭니다**
- 사진 제목이 부제 자리에 표시됩니다
- 버튼 위가 아니면 제목·부제 위를 쓸어도 넘어갑니다

사진 출처는 두 가지입니다.

| | 키 | 내용 |
|---|---|---|
| 위키미디어 | 필요 없음 | **그 장소의 실제 사진.** 기본이자 첫 장 |
| Pexels | `PEXELS_API_KEY` | 분위기 사진. 키를 넣으면 뒤에 붙습니다 |

Pexels 키는 https://www.pexels.com/api/ 에서 무료로 받아 `.env` 에 넣으면 됩니다.
실제 사진을 앞에 두는 이유는, 도슨트가 *"정면을 보세요"* 라고 말하는 앱이라
화면의 사진이 그 자리와 달라지면 안 되기 때문입니다.

```bash
.venv/bin/python photos.py 경주 첨성대   # 몇 장이 모이는지 확인
```

### 미니멀

- 상자와 테두리를 없애고 글자 크기와 여백으로만 위계를 만듭니다
- 재생 시간은 **진행바를 잡는 동안에만** 나타납니다
- 탭 이름은 **지금 있는 탭에만** 보입니다
- 재생 중에는 상단 상태 문구가 사라집니다
- 해설 화면은 손대면 4초간 자동 따라가기를 멈췄다가 다시 따라갑니다

### 스크롤

페이지는 절대 스크롤되지 않습니다. `100dvh` 그리드로 사진이 남는 공간을 차지하고,
화면이 낮아지면 문장 미리보기가 한 줄로 줄었다가(≤700px) 사라집니다(≤600px).
375×812 / 375×667 / 데스크톱에서 확인했습니다.

| 탭 | |
|---|---|
| **지금 여기** | 플레이어 |
| **해설** | 지금 읽는 문장이 밝아지는 가사 화면. 문장을 누르면 그 대목으로 이동 |
| **지나온 길** | 지나온 장소. ▶ 로 다시 재생 |

| 컨트롤 | |
|---|---|
| ▶ / ⏸ / ↺ | 재생·일시정지. 끝나면 다시 듣기로 바뀜 |
| ⏮ ⏭ | 이전 / 다음 **문장** |
| 진행바 | 끌어서 이동. 문장 단위로 붙음 |
| ⤨ | 같은 자리에서 다른 대목을 새로 해설 |
| 🚶 | 켜두면 70m 이상 이동할 때 자동 안내 |

## 해설 말투

`llm.py` 의 `SYSTEM` 프롬프트를 **설민석 선생님 같은 이야기꾼** 으로 맞춰 두었습니다.

- 초등학교 1학년이 옆에서 들어도 알아들을 수 있는 말만 씁니다
- 훅으로 시작하고, 질문을 던지고, 반전을 넣습니다
- 숫자는 몸으로 느끼게 바꿉니다 — "9.4미터" 대신 "어른 키의 다섯 배"
- 지정 번호나 행정 분류처럼 귀로 들으면 지루한 것은 읽지 않습니다
- **사실은 위키백과 자료에서만** 가져옵니다. 말투만 실감나게 하고 사실은 지어내지 않습니다

> ⚠️ **이 말투는 AI 키가 있어야 나옵니다.**
> 키가 없으면 위키백과 원문을 읽는 방식으로 동작합니다. 이때도 문어체(`~이다`)를
> 말하는 투(`~이에요`)로 바꾸고, 단위 기호를 소리내어 풀고, 행정 문장을 걷어내지만,
> **이야기로 재구성하지는 못합니다.** 위 3번 항목대로 무료 Gemini 키를 넣어 주세요.

## 목소리

브라우저 내장 음성합성을 씁니다. 앱이 알아서 이 기기에서 **가장 자연스러운
한국어 목소리**를 골라줍니다. (애플 기기라면 보통 *유나*)

설정 → **목소리 고르기** 에서 다섯 가지 중 고릅니다. 카드를 누르면 바로 들려줍니다.

| | 속도 | 높낮이 | 문장 사이 쉼 |
|---|---|---|---|
| 다정한 해설가 (기본) | 0.95 | 1.06 | 0.42초 |
| 신나는 이야기꾼 | 1.05 | 1.14 | 0.30초 |
| 차분한 다큐 내레이터 | 0.85 | 0.96 | 0.52초 |
| 낮고 묵직한 목소리 | 0.90 | 0.82 | 0.46초 |
| 또박또박 선생님 | 1.00 | 1.00 | 0.36초 |

같은 음성이라도 속도·높낮이·쉼을 바꾸면 다른 사람처럼 들립니다.
아래 **기기 목소리**에서 음성 자체를 바꿀 수도 있고, 속도·높낮이 슬라이더로 더 다듬을 수 있습니다.

**기계 티를 없애는 가장 확실한 방법은 프리미엄 음성을 한 번 내려받는 것입니다.**

- macOS — 시스템 설정 → 손쉬운 사용 → 음성 콘텐츠 → 시스템 음성 → *음성 관리* → 한국어 → **유나(프리미엄)**
- iOS — 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 음성 → 한국어 → **유나(프리미엄)**

내려받은 뒤 앱을 새로고침하면 목록에 나타나고, 자동으로 그 목소리를 씁니다.

> 유인나 같은 **실제 배우·성우의 목소리**는 그 사람과 계약해 만든 상용 TTS
> (카카오·네이버 등)에서만 나옵니다. 공개 API로는 쓸 수 없고, 음성 샘플로
> 흉내내는 복제는 본인 동의 없이 하면 안 되는 일입니다.

## 파일

```
server.py     HTTP 서버, SSE 스트리밍, HTTPS 인증서
wiki.py       위키백과 좌표 검색·본문 수집 (단독 실행 가능)
llm.py        해설 대본 생성. Gemini / Claude / 위키백과 자동 선택
photos.py     캐러셀 사진 수집. 위키미디어 + Pexels (단독 실행 가능)
web/app.js    GPS 추적, SSE 수신, 문장 분할, 플레이어, 캐러셀, 색 추출
web/index.html, web/style.css   음악 플레이어형 UI
```

말투와 구성은 `llm.py`의 `SYSTEM` 프롬프트에서 고칩니다.
위키백과 모듈만 따로 확인해볼 수 있습니다:

```bash
.venv/bin/python wiki.py 첨성대
```

## 알려진 한계

- **위키백과에 문서가 없는 곳은 안내할 수 없습니다.** 유명 문화재는 잘 나오지만
  동네 골목이나 최근 생긴 장소는 "자료를 찾지 못했습니다"가 뜹니다.
- 첫 문장이 나오기까지 5초쯤 걸립니다. AI가 대본을 쓰는 시간입니다.
- Gemini 무료 한도를 넘기면 잠시 막힙니다. 그때는 한도가 풀릴 때까지 기다리거나,
  `.env`에서 키를 지우면 위키백과 모드로 계속 쓸 수 있습니다.
- 밖에서 쓰려면 노트북이 같은 와이파이에 있어야 합니다. 진짜 여행지에서 쓰려면
  ngrok 같은 터널이나 서버 배포가 필요합니다.
- 브라우저 내장 음성합성이라 억양에 한계가 있습니다. 프리미엄 음성을 내려받으면
  많이 나아지지만, 상용 성우 TTS만큼은 아닙니다.
- 위키백과에 대표 사진이 없는 곳은 앨범아트가 비어 있습니다.
