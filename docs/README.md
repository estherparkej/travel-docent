# 여행 도슨트 — 웹앱

서버가 필요 없습니다. 이 폴더를 그대로 정적 호스팅에 올리면 동작합니다.
위키백과 · Gemini · Pexels · OpenStreetMap 을 브라우저가 직접 호출합니다.

## API 키

**코드에 키를 넣지 마세요.** 앱을 열고 설정 → AI 키에서 입력하면
그 기기의 브라우저에만 저장됩니다. 배포 파일에는 키가 없습니다.

키가 없어도 위키백과를 읽어주는 방식으로 동작합니다.

## 아이폰에 설치

1. 사파리로 배포 주소를 엽니다
2. 공유 → **홈 화면에 추가**
3. 설정 → AI 키에 Gemini 키 입력 (무료: aistudio.google.com/apikey)

걸어 다니며 화면을 끄고 들으시려면 설정에서 **구글 목소리**를 켜세요.
기기 목소리는 화면이 꺼지면 iOS 가 중단시킵니다.
